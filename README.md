# 서울 짝 맞추기

서울의 명소와 음식으로 즐기는 카드 짝 맞추기 웹 게임입니다.

▶ 플레이하기: https://jsuhyeon.github.io/seoul-memory-game/

## 주요 기능
- 난이도 선택 (카드 12 / 16 / 20장)
- 효과음과 애니메이션 (Web Audio API 사용, 음원 파일 없음)
- 난이도별 최고 기록 저장
- 모바일 터치와 다크 모드 지원

## 사용 기술
HTML, CSS, JavaScript (외부 라이브러리 없음)

## 만든 과정
Claude의 도움을 받아 만든 학습 프로젝트입니다.
기획과 수정 요청, 기기별 테스트는 직접 진행했습니다.

## 겪은 문제와 해결
- iPhone Safari에서 카드 그림이 보이지 않는 문제를
  Safari 전용 CSS 표기를 추가해 보완했습니다.
- 파일 이름이 index.html.html로 저장되어 배포가 404가 된 것을
  확장자 표시를 켜서 찾아 고쳤습니다.
